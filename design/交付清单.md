# 形象设计 · 交付清单

> 角色：形象设计师。
> 只产出设定、图和视频。**不改代码、不跑预览、不碰部署**；落地与适配由开发运维负责。

## 一、目录职责

| 目录 | 放什么 | 格式 |
|---|---|---|
| `design/spec/` | 角色设定：性格、口癖、语气、配色体系、服装规范、世界观 | Markdown |
| `design/art/` | 立绘、表情差分、时装、场景图、UI 素材 | PNG / WebP |
| `design/video/` | 开场 CG、宣传短片 | MP4 (H.264) |
| `design/audio/` | 三形态配音、音效 | WAV / MP3 |

## 二、交付规格

| 类别 | 要求 |
|---|---|
| 全身立绘 | 三形态（御姐 / 少女 / 萝莉）× 双主题（日间 / 夜间哥特），PNG 透明底，高度统一 1200px |
| 表情差分 | 与主体**同画布同锚点**，只换表情，方便换图不跳动 |
| 时装 | 六套，4:5 竖版（形象页陈列用） |
| 场景图 | 群聊生活场景，16:9 |
| 开场视频 | 1920×1080，≤15 MB（进仓库要控体积） |
| 配音 | 三形态各一套，单句 8–20 秒，命名区分形态与台词 |

## 三、命名规范

```
art/  形态-主题-用途.png     如：御姐-夜间-全身.png
      表情-形态-情绪.png     如：表情-少女-晕晕.png
      时装-序号-名称.png     如：时装-03-粉色兔兔.png
video/  用途-版本.mp4        如：开场-CG-v2.mp4
audio/  形态-台词序号.wav    如：御姐-01.wav
```

同一套素材**版本迭代请覆盖同名或递增序号**，不要出现 `最终版`、`最终版2`、`真的最终版`。

## 四、交接方式（单向）

```
design/art/  →  cloud/assets/     （开发执行复制，不反向回写）
design/spec/ →  开发阅读后写进页面文案
design/video/→  cloud/assets/video/
design/audio/→  cloud/assets/audio/
```

`design/` 是**唯一素材源**，`cloud/assets/` 是**发布产物**。只允许 design → cloud 单向流动，任何人不得从 cloud 反向覆盖 design。

## 五、验收红线

1. **出图必须给出最终页面用的尺寸和格式**，不要只给一张大图让开发去切。
2. 透明底图的边缘不要发灰，深色主题下要能看清。
3. 缩略图尺寸（约 320px 宽）下主体要可辨认，线条别细到糊掉。
4. 一次交付一个完整套系，不要散着给，避免开发反复适配。
