# 汐音 · 服装与立绘风格规范

- 版本：v1.0（2026-11-18）
- 适用范围：知潮看板娘「汐音」的立绘、换装、服装提案、表情、头像、周边设计
- 定版依据：`汐音-粉兔兔冬装-日系-灰调.png`（用户 2026-11-18 确认「发灰的最贴近日系」）

---

## 0. 一句话定义

**灰调日系动画设定图**：细而柔的勾线 + 薄平涂 + 低对比通透发灰，像动画角色设定集里的淡彩稿，而不是商业插画里的厚涂成品。

判断标准：把图缩小到 30% 看，如果线条还在、色块边界还在、整体淡得像蒙了一层雾——对了。如果看起来像水彩画、像厚涂、像 AI 插画，都不对。

---

## 1. 不变量与可变量

换任何衣服，以下身份锚点都不能动：

| 类型 | 锚点 |
|---|---|
| 头部 | 烟粉长卷发、紫粉色眼睛、星月发饰（月牙 + 小星） |
| 体型 | 七头身、细长腿、自然人体比例（不做 Q 版） |
| 元素 | 浪花纹样（衣摆、刺绣、贴饰） |
| 调性 | 低饱和粉系、柔和不刺眼 |

可以变：服装款式、剪裁、局部配饰、道具、场景、镜头、裁切。

## 2. 画风参数表（可量化，复现按此核对）

| 维度 | 要求 | 典型反例 |
|---|---|---|
| 线稿 | 极细且柔，深灰褐（约 `#6B5F66`–`#7A6A70`），1024 画布下约 1–2px；允许局部断线留白 | 粗黑描边、卡通勾线、无描边纯色块 |
| 上色 | 薄平涂，色块边界干净可辨 | 厚涂、笔触堆叠、水彩晕染 |
| 明度 | 主体色集中在高明度区间（约 78–95） | 中低明度、深色重色块 |
| 阴影 | 只保留一阶单色阴影，色相取淡粉紫（约 `#E8D6DE`） | 二阶/三阶阴影、硬投影、大面积暗部 |
| 对比 | 整体偏淡、通透，但**轮廓与色块边界必须清晰** | 整张发白丢轮廓；或强对比赛璐璐 |
| 高光 | 小面积，发丝用浅蓝细线条，不发光晕 | 大面积渐变高光、油亮质感 |
| 脸部 | 眼线细、瞳孔淡紫带小面积高光、腮红淡、五官简洁克制 | 浓睫毛、厚眼线、写实五官 |
| 背景 | 纯色浅粉 `#F6E8E8` 或米白 `#FBF4F1`，无装饰 | 场景背景、渐变背景、光斑 |

**禁止项**：厚涂、笔触、水彩晕染、纸纹/颗粒噪点、粗黑描边、强投影、荧光高饱和、3D 光泽皮肤、写实皮肤毛孔、大面积光晕。

## 3. 提示词模板（图生图，直接复制改服装段）

```
【身份段】保留图一角色的脸型、紫粉色眼睛、烟粉长卷发、星月发饰与七头身比例，
【服装段】仅把服装换成：<服装描述：版型 + 材质 + 配色 + 关键配饰 + 道具>，
【风格段】画风为灰调日系动画设定图：极细而柔和的深灰褐色勾线、薄而干净的平涂色块、
单一淡粉紫一阶淡阴影、无厚涂无笔触无水彩晕染无颗粒无渐变、整体明度偏高对比偏淡
但轮廓锐利清晰、色块边界干净不发灰、自然人体比例、简洁带透明感的大眼睛、纯浅粉背景。
【负向】厚涂、水彩、纸纹颗粒、粗黑描边、荧光高饱和、3D 渲染、写实照片、复杂背景、文字水印。
```

**两个关键写法（踩过坑，必须保留）**：

1. **不要只写「极细线 + 无笔触」**。模型会理解为整体褪色，出图发雾、丢轮廓。必须同时写「轮廓锐利、色块边界干净」，才能细而不糊。
2. **不要写「无渐变」又同时要求「柔和」**。二者冲突会让画面变得脏。柔和的实现方式是压对比度、加淡阴影，不是加渐变。

## 4. 参考图使用规则

| 场景 | 参考图配置 | 提示词必须写明 |
|---|---|---|
| 已有角色换装 | 单图：当前定版立绘 | 保留身份锚点，只换服装 |
| 指定画风复刻 | 图一 = 身份图（汐音母版），图二 = 画风图 | 「图一只提供人物身份，图二只提供画风，不提供人物；禁止借用图二的发型、服装、姿势」 |
| 旧图换风格 | 单图：要保留的旧图 | 明确「构图、姿势、服装细节完全不变，只改画风」 |

- 身份图首选：`live2d/source/xiyin-artwork-complete.png`（母版）或当前定版。
- 画风图：用户指定的日系动画参考图（2026-11-18 提供，`https://aka.doubaocdn.com/s/r0ArvLO2So`）。
- 多图时如果只写「参考这两张」，模型会把两个角色特征混合——发色、五官会被带跑。

## 6. 立绘 → 微信头像标准流程

1. 以定版立绘为唯一参考生成头肩特写（只含头部到胸口以上，正面微侧，看镜头，浅笑）。
2. 头像构图：人物居中，**头部占画面高度 60–70%**，兔耳与发梢顶部、左右各留 ≥6% 安全区。
3. 出图后检查兔耳/发梢是否贴边——立绘直裁的圆图，兔耳尖常被裁掉。
4. 做安全边距版：原图缩至 88%，居中贴到同色底色画布，避免圆裁切到耳朵。
5. 生成深灰底圆形预览确认，无裁切才交付。
6. 交付方形 PNG（微信客户端自动圆裁），不用交圆形图。

## 7. 迭代记录（避免重复走弯路）

| 版本 | 做法 | 结果 |
|---|---|---|
| v1 水彩淡彩 | 柔光、渐变、笔触 | 否——「AI 插画感太重」 |
| v2 粗线赛璐璐 | 粗黑描边、硬边阴影 | 否——「这才正常日系吗」 |
| v3 细线薄涂 | 细勾线、减阴影、自然比例 | 方向对了，但对比仍偏高 |
| v4 灰调定版 | 参照指定画风图，整体提亮发灰 | **采用**——「发灰的最贴近日系」 |
| 备选·冷发色 | 发色改深雾紫粉 | 未采用，偏离烟粉设定，仅留档 |

**核心经验**：往「亮、淡、灰」调，就是日系设定图；往「鲜艳、立体、有质感」调，就变商业插画。发色、瞳色一旦加深，整个人会立刻偏向插画感。
